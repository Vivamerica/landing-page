# Guia de Imagens — Terras de San Marino

Copie as imagens para a pasta `images/` e renomeie conforme abaixo.

## Imagens obrigatórias

| Nome do arquivo         | Qual imagem usar                                      |
|-------------------------|-------------------------------------------------------|
| `logo-san-marino.png`   | Logo San Marino Residencial (fundo transparente)      |
| `hero.jpg`              | Melhor render do empreendimento (portaria ou piscina) |
| `implantacao.jpg`       | Mapa de implantação / urbanístico (PNG do PDF)        |
| `piscina.jpg`           | Piscina resort em formato cruz com solário            |
| `food-truck.jpg`        | Food Truck Park com iluminação de bulbos              |
| `tenis.jpg`             | Quadra de tênis (vista aérea vermelho/azul)           |
| `padel.jpg`             | Quadra de padel                                       |
| `beach-volei.jpg`       | Quadra de beach vôlei (areia)                         |
| `futebol.jpg`           | Campo de futebol society (grama natural)              |
| `academia-salao.jpg`    | Fachada com "Academia / Salão de Festas"              |
| `gourmet.jpg`           | Espaço gourmet coberto com bar/cozinha                |
| `playground.jpg`        | Área de playground / pista de bike                    |

## Galeria (6 imagens)

| Nome do arquivo | Qual imagem usar                          |
|-----------------|-------------------------------------------|
| `gal-1.jpg`     | Portaria monumental (frontal)             |
| `gal-2.jpg`     | Piscina (horizontal, formato wide)        |
| `gal-3.jpg`     | Food Truck Park (horizontal, formato wide)|
| `gal-4.jpg`     | Pergola / espaço gourmet                  |
| `gal-5.jpg`     | Quadras esportivas (visão geral)          |
| `gal-6.jpg`     | Jardins / área verde com fonte            |

## Dicas de conversão

- Converta as imagens para `.jpg` com qualidade 85% para carregamento rápido
- Tamanho ideal: máximo 1920px de largura
- Ferramenta gratuita: squoosh.app (arraste a imagem, exporte como JPEG)
- O logo deve ser `.png` com fundo transparente
